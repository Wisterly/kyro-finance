1. Exercício do Caminho de Confirmação Usado pelo Chat (ChatVoiceController + Rota HTTP + Firestore Emulator)

Em vez de chamada direta ao adaptador contábil, o fluxo conecta a interface do usuário (src/App.tsx) ao controlador reativo (ChatVoiceController), comunicando-se via fetch com a rota oficial POST /api/database sobre o Firestore Emulator e autenticação Firebase Admin:

Ponto de Ligação Arquitetural Comprovado:
• Interface (src/App.tsx): Botões Microfone (startRecordingAudio), Lixeira/Cancelar (cancelRecordingAudio) e Lançar (stopRecordingAudio) acionam diretamente a instância conectada chatVoiceController.
• Controlador (src/services/chatVoiceController.ts): Higieniza transcrição, isola buffers visuais (zero mutações em parciais/cancelamento) e despacha confirmação deliberada.
• Rota HTTP (POST /api/database): Processa save_transaction exigindo Bearer ID Token oficial do Firebase Auth Emulator e cabeçalho X-Request-ID.
• Persistência (Firestore Emulator): Aplica o efeito contábil em lote atômico e comita o recibo transacional APPLIED.
