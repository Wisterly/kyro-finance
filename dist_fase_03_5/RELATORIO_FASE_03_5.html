5. Parecer Oficial e Protocolo Detalhado de Rollback (para quem instalou o Build 46)

Portanto, caso haja necessidade de reverter uma base de usuários que já instalou o Build 46 (versão 1.46), o procedimento formal de reversão transparente é o seguinte:
